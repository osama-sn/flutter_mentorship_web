بتشوف فيديوهات كتير وبتطبق قليل

الفيديو بيبان سهل وأنت بتتفرج، بس أول ما تقفل الشاشة وتيجي تبدأ كود بنفسك، بتلاقي نفسك مش عارف تكتب سطر واحد وتائه.

بتبدأ مشاريع ومبتكملهاش

دايماً عندك الحماس للبداية، بس لما المشروع يكبر والتحديات تزيد بتزهق أو متعرفش تحل المشاكل المعقدة وتسيبه ناقص.

مش عارف تبني مشروع كامل لوحدك

حافظ الـ widgets الأساسية، بس مش عارف تربط الـ UI بالـ API والـ database وتعمل flow متكامل لتطبيق شغال وحقيقي.

معندكش Portfolio قوي

مشاريعك هي مجرد تطبيقات كورس تقليدية (تودو، آلة حاسبة) شبه مشاريع آلاف الخريجين ومبتلفتش انتباه أي HR أو شركة.

مش عارف تدور على شغل أو Internship

مشكلتك مش بس الكود، أنت مش عارف تسوق لنفسك على LinkedIn و GitHub أو تعدي الإنترفيو التقني والأسئلة الصعبة.

مشروع التخرج هو تطبيق كامل بمقاييس احترافية (تطبيق Travel Agency App). بنبني فيه Clean Architecture ونستخدم الـ BLoC مع الـ REST APIs. وأفضل مشروع تخرج منفذ من الطلاب هيتم مراجعته ورفعه على متجر Google Play على حسابنا كحافز للجميع.
نعم، عندنا مجتمع طلابي مغلق وقنوات مخصصة للمناقشات وحل الأخطاء البرمجية (Errors). تقدر تبعت مشكلتك وهيتم الرد عليك وحلها بمساعدتنا ومساعدة زملائك، بالإضافة للمراجعة الأسبوعية لكودك.
بنحدد العدد بحيث لا يتخطى عدد مناسب للمجموعة الواحدة للدفعة. الهدف هو الحفاظ على جودة المتابعة ومراجعة أكواد كل طالب سطر بسطر والتوجيه الفردي.
تحتاج لجهاز كمبيوتر أو لابتوب برامات لا تقل عن 8 جيجابايت (ويفضل 16 جيجابايت لتشغيل المحاكي بسلاسة)، ومعالج Core i5 أو ما يعادله لضمان تجربة تطوير مريحة بدون بطء.
نعم بالتأكيد! التواصل بيكون مباشر في المحاضرات الـ Live، وعن طريق الـ Code Reviews الأسبوعية اللي بيعملها أسامة بنفسه لكودك، وبتقدر تتواصل معاه على الجروب المخصص للطلاب لحل أي عوائق.
